## Epic 1: Agent Runner

Берёт запуск из очереди ICPlan, выдаёт sandbox из тёплого пула, следит за лимитами, возвращает итог.

### Story 1.1: забрать запуск из очереди и исполнить его в изолированной среде

As a Агент-исполнитель (система),
I want забрать запуск из очереди и исполнить его в изолированной среде,
So that задача ICPlan выполнялась агентом платформы.

Код: US-RUN-01. Требования: FR-66, FR-72, FR-73, NFR-5.

**Acceptance Criteria:**

**Given** Запуск взят
**When** выполняется сценарий
**Then** создан sandbox, Harness получил задание

**Given** Агент выключен или нет настроек
**When** выполняется сценарий
**Then** `agent_unavailable`, sandbox не создаётся

**Given** Нет свободного слота
**When** выполняется сценарий
**Then** запуск ждёт в `queued`

**Given** Переключение при активных запусках
