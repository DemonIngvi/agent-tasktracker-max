# Правила проекта

Перед работой прочитайте навык `doc-arch`: он говорит, какой файл владеет каким фактом и что обновлять после изменения.

- Работайте в папке компонента: `docs/architecture/components/<компонент>/`.
- Не копируйте факт, а ссылайтесь на него кодом или относительным путём.
- Общие `prd.md`, `epics.md` и Spine собираются, руками не правятся.
- Docmost только генерируется: `uv run ../doc-publisher/tools/publish.py --root .`
- `tools/migrate.py` выполнил разовый перенос. После ручных правок не запускайте его.
- В конце работы выполните `check.py`.
