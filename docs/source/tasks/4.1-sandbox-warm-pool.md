## Зачем

Убрать задержку старта контейнера, не жертвуя изоляцией.

## Что сделать

- Пул N контейнеров на профиль
- claim / destroy / долив
- Метрики пула

## Приёмка

- [ ] Запуск стартует без создания контейнера
- [ ] После запуска пул снова N
- [ ] Пул профиля пуст → sandbox создаётся заново, запуск ждёт старта; изменён образ профиля → пул пересоздаёт контейнеры ([FR-83](../../architecture/components/sandbox/prd.md))
- [ ] Нет ресурсов хоста → запуск ждёт в `queued`, пул уменьшается; образ недоступен → профиль помечен недоступным, запуски отклоняются ([FR-93](../../architecture/components/sandbox/prd.md))
- [ ] Быстрый старт → запуск начинается без создания контейнера, после завершения контейнер уничтожен, в пуле снова N свободных ([FR-83](../../architecture/components/sandbox/prd.md))

**Как прокликать:** Делегировать задачу → старт < 1 с; `docker ps` показывает N свободных
