## Зачем

Первая связь с [ICPlan](../../architecture/components/icplan/README.md): задачи из очереди [ICPlan](../../architecture/components/icplan/README.md) выполняет наш [Harness](../../architecture/components/harness/README.md), а не CLI на машине оператора.

## Что сделать

- Каркас Runner (Go)
- Опрос очереди [ICPlan](../../architecture/components/icplan/README.md) по ключу агента (протокол `@itsaplan/runner`)
- Запуск [Harness](../../architecture/components/harness/README.md), приём событий, стрим ответа в [ICPlan](../../architecture/components/icplan/README.md), итог
- Таймаут и отмена
- Параллельность на агента
- Манифест рабочего пространства из политики доступа → [Sandbox](../../architecture/components/sandbox/README.md) и [`RunBundle`](../../architecture/data/model-RunBundle.yaml)

## Приёмка

- [ ] Делегированная внешнему агенту задача → ответ в комментарии
- [ ] Отмена в [ICPlan](../../architecture/components/icplan/README.md) останавливает запуск
- [ ] Таймаут → статус failed с причиной
- [ ] Задача делегирована внешнему агенту → запуск в очереди [ICPlan](../../architecture/components/icplan/README.md), Runner его забирает; задача внутреннему агенту — Runner не забирает; отозванный ключ → отказ в доступе, запуски не выдаются ([FR-1](../../architecture/components/icplan/prd.md))
- [ ] Очередь пуста → Runner ждёт интервал опроса без ошибок; Runner остановлен → запуск ждёт и исполняется после старта; очередь не отвечает → опрос с растущей задержкой и событие о недоступности ([FR-2](../../architecture/components/icplan/prd.md))
- [ ] Два экземпляра Runner опрашивают одновременно → запуск получает один; Runner упал после получения → по истечении аренды запуск выдаётся снова; повторный опрос не выдаёт взятый запуск ([FR-3](../../architecture/components/icplan/prd.md))
- [ ] Итог с вложением → в задаче комментарий и вложение; без вложений → один комментарий; обрыв стрима → пропущенные шаги досылаются по номерам, дублей нет ([FR-4](../../architecture/components/icplan/prd.md))
- [ ] Отмена → [Harness](../../architecture/components/harness/README.md) остановлен, sandbox уничтожен; отмена завершённого запуска → статус не меняется; отмена при ожидании approve → `canceled`, запрос подтверждения закрыт ([FR-7](../../architecture/components/icplan/prd.md))
- [ ] Несовместимая версия протокола → Runner не забирает запуски и сообщает; совпадающая — запуски выдаются; необязательное поле от [ICPlan](../../architecture/components/icplan/README.md) игнорируется ([FR-9](../../architecture/components/icplan/prd.md))
- [ ] Runner не в сети → агенты «не в сети», запуски ждут; RustFS недоступно → итог публикуется без вложений, загрузка повторяется ([FR-17](../../architecture/components/icplan/prd.md))
- [ ] Запуск завершён → в M2 запись с итогом, статусом и токенами; ошибочный запуск → запись с причиной; БД [ICPlan](../../architecture/components/icplan/README.md) недоступна → итог досылается, M2 без дублей по `run_id` ([FR-38](../../architecture/components/memory/prd.md))
- [ ] Запуск в очереди → Runner создаёт запись с `run_id` в `queued`; агент выключен или не найден → `agent_unavailable`, sandbox не создаётся; указана версия 3 при последней 5 → исполняется версия 3 ([FR-66](../../architecture/components/agent-runner/prd.md))
- [ ] Смена `queued` → `running` → событие в [ICPlan](../../architecture/components/icplan/README.md); `gate_failed` → в [ICPlan](../../architecture/components/icplan/README.md) `failed` с пометкой «не прошёл проверку»; перезапуск Runner → статусы восстановлены из S3 без дублей ([FR-72](../../architecture/components/agent-runner/prd.md))
- [ ] Успешное завершение → `succeeded`, результат по `run_id`; результат не по формату → `gate_failed`; остановка по лимиту → частичный итог с пометкой «не завершено» ([FR-73](../../architecture/components/agent-runner/prd.md))
- [ ] Отмена в очереди → снят без создания sandbox; повторная отмена → статус не меняется, ошибки нет ([FR-74](../../architecture/components/agent-runner/prd.md))
- [ ] Репозиторий (write) и папка (read) в политике → манифест с обоими источниками уходит в [Sandbox](../../architecture/components/sandbox/README.md) и [`RunBundle`](../../architecture/data/model-RunBundle.yaml); нет политики → пустой манифест и событие; [Platform module](../../architecture/components/platform-module/README.md) не ответил → запуск не стартует, «нет политики доступа» ([FR-76](../../architecture/components/agent-runner/prd.md))
- [ ] [ICPlan](../../architecture/components/icplan/README.md) недоступен → опрос с backoff, активные запуски идут, события буферизуются; [Platform module](../../architecture/components/platform-module/README.md) недоступен → новые запуски не стартуют; Docker или пул недоступны → запуск остаётся в `queued`; Runner упал → запуски возвращаются в очередь, слоты свободны ([FR-80](../../architecture/components/agent-runner/prd.md))
- [ ] MCP-сервер недоступен → агент получает ошибку тула; шаг подготовки упал или превысил `setup.timeout_s` → `failed` с причиной «подготовка среды»; нет настроек агента или ключа → `agent_unavailable` ([FR-80](../../architecture/components/agent-runner/prd.md))
- [ ] Успешный запуск → Runner берёт его, создаёт запись с `run_id` и статусом `queued` ([FR-66](../../architecture/components/agent-runner/prd.md))
- [ ] Терминальный статус → итог с причиной отправлен в [ICPlan](../../architecture/components/icplan/README.md), статус в [ICPlan](../../architecture/components/icplan/README.md) — `failed` с пометкой «не прошёл проверку» ([FR-72](../../architecture/components/agent-runner/prd.md))
- [ ] Выше максимума → значение отклонено, ошибка называет `scheduling.aging_s` и границы 60–3600 ([FR-77](../../architecture/components/agent-runner/prd.md))
- [ ] Граница от другого параметра → значение отклонено: `concurrency` не может быть больше `scheduling.global_max` ([FR-77](../../architecture/components/agent-runner/prd.md))
- [ ] Значение по умолчанию → применяется значение по умолчанию: 600 ([FR-77](../../architecture/components/agent-runner/prd.md))
- [ ] Аутентификация [I2](../../architecture/components/agent-runner/integrations/I2.yaml) → вызов не повторяется, событие с причиной ([FR-79](../../architecture/components/agent-runner/prd.md))
- [ ] Неидемпотентный вызов [I6](../../architecture/components/agent-runner/integrations/I6.yaml) → автоматического повтора нет, решение принимает вызывающий ([FR-79](../../architecture/components/agent-runner/prd.md))
- [ ] Таймаут [I1](../../architecture/components/agent-runner/integrations/I1.yaml) → вызов прерывается; повтор: backoff до 60 с ([FR-79](../../architecture/components/agent-runner/prd.md))
- [ ] Манифест собран → манифест содержит оба источника с правами и уходит в [Sandbox](../../architecture/components/sandbox/README.md) и [`RunBundle`](../../architecture/data/model-RunBundle.yaml) ([FR-76](../../architecture/components/agent-runner/prd.md))
- [ ] Политика недоступна → запуск не стартует, причина «нет политики доступа» ([FR-76](../../architecture/components/agent-runner/prd.md))
- [ ] Платформа недоступна → запуск ждёт в очереди и исполняется после запуска Runner ([FR-2](../../architecture/components/icplan/prd.md))
- [ ] Минорное обновление → Runner продолжает работать, поле игнорируется ([FR-9](../../architecture/components/icplan/prd.md))
- [ ] Выше максимума → значение отклонено, ошибка называет `agent.delegation_delay_sec` и границы 0–86400 ([FR-14](../../architecture/components/icplan/prd.md))
- [ ] Значение по умолчанию → применяется значение по умолчанию: internal ([FR-14](../../architecture/components/icplan/prd.md))
- [ ] S1 недоступно → выдача запусков и приём итогов останавливаются; Runner повторяет с backoff, итог держит до восстановления ([FR-15](../../architecture/components/icplan/prd.md))
- [ ] Секрет в БД → в S1 попадает только шифротекст; из дампа БД без `APP_ENCRYPTION_KEY` ключ не прочитать ([FR-15](../../architecture/components/icplan/prd.md))
- [ ] Права по [I20](../../architecture/components/icplan/integrations/I20.yaml) → API [ICPlan](../../architecture/components/icplan/README.md) отклоняет запрос (403), данные не меняются, событие в журнале ([FR-16](../../architecture/components/icplan/prd.md))
- [ ] Таймаут [I1](../../architecture/components/agent-runner/integrations/I1.yaml) → вызов прерывается; повтор: backoff до 60 с ([FR-16](../../architecture/components/icplan/prd.md))
- [ ] Нет обязательного параметра → модуль не стартует, ошибка называет `protocol.version` ([FR-14](../../architecture/components/icplan/prd.md))
- [ ] Запись в своё хранилище → запись попадает в S1 (PostgreSQL 17 (CloudNativePG), БД `itsaplan`) ([FR-15](../../architecture/components/icplan/prd.md))

**Как прокликать:** [ICPlan](../../architecture/components/icplan/README.md): агент «внешний» в сети → делегировать задачу → комментарий агента
