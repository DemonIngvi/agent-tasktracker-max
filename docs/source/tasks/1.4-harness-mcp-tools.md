## Зачем

Без тулов агент только отвечает текстом. Allowlist из конфига — первая граница безопасности (до OPA).

## Что сделать

- Подключение MCP-серверов из определения агента (адаптер MCP → тулы LangGraph)
- Allowlist: агенту видны только перечисленные тулы
- Таймауты и ошибки тулов возвращаются агенту как результат, цикл продолжается
- Тестовый MCP-сервер (echo / файлы) для проверок
- Описание рабочего пространства в контексте, тулы только внутри `/workspace`, артефакты в [`RunResult`](../../architecture/data/model-RunResult.yaml)

## Приёмка

- [ ] Агент вызывает тул MCP и получает результат
- [ ] Тул вне allowlist не виден и не вызывается
- [ ] Таймаут тула → ошибка в результате, запуск не падает
- [ ] Новый MCP-сервер добавлен агенту → тулы доступны со следующего запуска; сервер не отвечает при регистрации → пометка «недоступен», тулы не выдаются; тот же адрес повторно → отклонено как дубликат ([FR-176](../../architecture/components/mcp-tools/prd.md))
- [ ] Тул ответил вовремя → результат агенту; ответ больше лимита → обрезан с пометкой, контекст не переполняется ([FR-178](../../architecture/components/mcp-tools/prd.md))
- [ ] MCP-сервер недоступен → ошибка тула агенту; секрет не задан → тулы сервера недоступны, предупреждение; сервер изменил набор тулов → новые тулы не видны без allowlist ([FR-186](../../architecture/components/mcp-tools/prd.md))
- [ ] MCP-сервер недоступен → ошибка тула возвращается агенту, цикл продолжается ([FR-34](../../architecture/components/harness/prd.md))
- [ ] Запуск с манифестом из двух источников → агент видит пути и права; файловый тул с путём вне `/workspace` → отклонён; итог → [`RunResult`](../../architecture/data/model-RunResult.yaml) со списком артефактов; изменён lock-файл и вызван `install_dependencies` → шаг подготовки повторён, `/workspace/.deps` обновлён ([FR-29](../../architecture/components/harness/prd.md))
- [ ] Новые зависимости → Runner повторяет шаг подготовки ([AD-19](../../architecture/decisions/AD-19.yaml)), `/workspace/.deps` обновлён, цикл продолжается ([FR-29](../../architecture/components/harness/prd.md))
- [ ] Описание в контексте → агент видит пути и права в контексте ([FR-29](../../architecture/components/harness/prd.md))
- [ ] Вызов в обход [Harness](../../architecture/components/harness/README.md) → соединение недоступно: MCP-серверы доступны только через MCP-прокси Runner, вызов вне allowlist прокси отклоняет ([FR-177](../../architecture/components/mcp-tools/prd.md))
- [ ] Недоступный MCP → агент получает ошибку тула и продолжает цикл ([FR-178](../../architecture/components/mcp-tools/prd.md))
- [ ] Успешный вызов → результат возвращается агенту ([FR-178](../../architecture/components/mcp-tools/prd.md))
- [ ] Выше максимума → значение отклонено, ошибка называет `timeout_s` и границы 5–300 ([FR-183](../../architecture/components/mcp-tools/prd.md))
- [ ] Значение по умолчанию → применяется значение по умолчанию: itsaplan-core ([FR-183](../../architecture/components/mcp-tools/prd.md))
- [ ] Нет обязательного поля → сохранение отклонено, ошибка называет `auth.secret_ref` ([FR-183](../../architecture/components/mcp-tools/prd.md))
- [ ] S1 недоступно → тулы [ICPlan](../../architecture/components/icplan/README.md) возвращают ошибку агенту с типом «недоступно»; агент не повторяет записи сам ([FR-184](../../architecture/components/mcp-tools/prd.md))
- [ ] Запись в своё хранилище → запись попадает в S1 (PostgreSQL 17 (CloudNativePG), БД `itsaplan`) ([FR-184](../../architecture/components/mcp-tools/prd.md))
- [ ] Аутентификация [I17](../../architecture/components/sandbox/integrations/I17.yaml) → вызов не повторяется, событие с причиной ([FR-185](../../architecture/components/mcp-tools/prd.md))
- [ ] Неидемпотентный вызов [I9](../../architecture/components/harness/integrations/I9.yaml) → автоматического повтора нет, решение принимает вызывающий ([FR-185](../../architecture/components/mcp-tools/prd.md))
- [ ] Таймаут [I9](../../architecture/components/harness/integrations/I9.yaml) → вызов прерывается; повтор: чтение — 2 раза; запись — нет ([FR-185](../../architecture/components/mcp-tools/prd.md))
- [ ] Новый тул на сервере → агенту он не виден ([FR-177](../../architecture/components/mcp-tools/prd.md))

**Как прокликать:** автотест сценария на mock-LLM (CLI-запуск, вывод шагов): в шагах виден вызов тула и его ответ
