## Зачем

Фиксирует, что этап 2 работает целиком и не ломается при следующих доработках.

## Что сделать

- Автотест сценария: задача → делегат → Runner → контейнер → [Harness](../../architecture/components/harness/README.md) → MCP → M3 → итог
- Смена модели агента без перезапуска
- Автотесты отказов по [FR-17](../../architecture/components/icplan/prd.md), [FR-73](../../architecture/components/agent-runner/prd.md), [FR-80](../../architecture/components/agent-runner/prd.md)
- Инструкция ручной проверки

## Приёмка

- [ ] Автотест проходит на локальном стеке
- [ ] Ручной сценарий по инструкции проходит
- [ ] Итог не по формату определения → запуск `gate_failed`; остановка по лимиту → в задаче частичный итог «не завершено» ([FR-73](../../architecture/components/agent-runner/prd.md))
- [ ] Runner не в сети → агенты «не в сети», запуски ждут; несовместимая версия протокола → Runner не берёт запуски ([FR-17](../../architecture/components/icplan/prd.md))
- [ ] RustFS недоступно → итог опубликован без вложений, загрузка повторяется ([FR-17](../../architecture/components/icplan/prd.md))
- [ ] [ICPlan](../../architecture/components/icplan/README.md) недоступен → опрос с backoff, активный запуск продолжается, события доставлены после восстановления ([FR-80](../../architecture/components/agent-runner/prd.md))
- [ ] [Platform module](../../architecture/components/platform-module/README.md) недоступен → новый запуск не стартует; Docker недоступен → запуск остаётся `queued` ([FR-80](../../architecture/components/agent-runner/prd.md))
- [ ] Runner упал → запуск вернулся в очередь, слот освобождён ([FR-80](../../architecture/components/agent-runner/prd.md))

**Как прокликать:** Пошаговая инструкция в документе: что нажать в [ICPlan](../../architecture/components/icplan/README.md) и что увидеть
