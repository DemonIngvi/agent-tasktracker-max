## Зачем

Расширение автоматизации (произвольные условия Действий) и видимость стоимости задачи. Процесс типа задачи — в 3.1.

## Что сделать

- Эффект Действия «делегировать агенту» (T-04)
- Затраты (токены, $) в задаче из LiteLLM: сумма по `metadata.run_id`; отклонение вызова без `run_id` — pre-call хук LiteLLM в 4.5 (AD-26)

## Приёмка

- [ ] Поставить метку, по которой Действие делегирует агенту → делегат — агент Действия, запуск в очереди; без метки — не срабатывает (FR-190 «Действие по метке», «Условие не выполнено»)
- [ ] Действие ссылается на выключенного агента → запуска нет, ошибка в истории задачи (FR-190 «Агент отключён»)
- [ ] Открыть задачу с тремя запусками → сумма токенов и $ по задаче (FR-150 «Затраты задачи», FR-135 «Подсчёт по запуску»)
- [ ] У модели нет цены → токены учтены, стоимость «неизвестна» (FR-150 «Нет данных о цене»)
- [ ] Запуск с ответом стримом и с ошибкой провайдера → в сумме задачи токены стрима есть, неуспешный вызов стоимости ответа не добавляет (FR-135 «Стрим», «Ошибка провайдера»; запись в журнал LiteLLM — 1.1)
- [ ] Отчёт по модели → возвращается сумма по всем агентам, использовавшим модель (FR-150)

**Как прокликать:** Поставить метку → агент Действия взял задачу; открыть затраты задачи
