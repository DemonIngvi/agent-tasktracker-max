## Зачем

Без лимитов агент может зациклиться и тратить токены; без управления контекстом длинные задачи падают на переполнении окна.

## Что сделать

- Лимиты шагов, времени, токенов из определения агента
- Завершение done / limit / error с частичным результатом
- Сжатие истории при приближении к окну модели

## Приёмка

- [ ] Лимит 3 шага → статус limit и частичный итог
- [ ] Переполнение окна → история сжата, запуск продолжается
- [ ] История меньше порога → сжатие не выполняется; контекст не помещается и после сжатия → `limit` с причиной `context_overflow` (FR-25)
- [ ] Итог содержит все обязательные разделы → `succeeded` с отметкой «gate пройден»; раздела нет и повторы исчерпаны → `gate_failed` с перечнем критериев; критериев нет → «gate не задан»; агент пытается изменить критерий своего шага → отклонено, событие (FR-26)
- [ ] Агент вернул итог → `done`; превышен максимум шагов → `limit` с частичным результатом; модель вернула ошибку после повторов → `error` с причиной и частичным итогом (FR-27)
- [ ] Memory API недоступен → запуск идёт без M3 и M2, событие-предупреждение (FR-34)
- [ ] `max_steps` исчерпан → `limit_exceeded` с частичным итогом; запуск дольше `timeout_s` → `limit_exceeded`, причина `timeout`; нет событий дольше `idle_s` → запуск остановлен, слот свободен (FR-119)
- [ ] Короткая история → сжатие не выполняется (FR-25)
- [ ] Переполнение контекста → старая часть истории сжимается, ключевые факты сохраняются (FR-25)
- [ ] Сжатие невозможно → запуск завершается `limit` с причиной `context_overflow` (FR-25)
- [ ] Успешное завершение → статус `done`, итог передан Runner (FR-27)
- [ ] Превышено время → статус `limit_exceeded` с причиной `timeout` (FR-119)
- [ ] Простой → запуск останавливается и освобождает слот (FR-119)
- [ ] Единичная ошибка → счётчик сбрасывается, запуск продолжается (FR-122)
- [ ] Повтор с задержкой → следующий вызов идёт с увеличенной задержкой (FR-122)
- [ ] Сервис недоступен → запуск останавливается с причиной `circuit_open`, а не крутится дальше (FR-122)

**Как прокликать:** автотест сценария на mock-LLM (CLI-запуск, вывод шагов): агент с маленьким лимитом останавливается со статусом limit
