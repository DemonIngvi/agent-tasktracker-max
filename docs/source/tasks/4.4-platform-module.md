## Приёмка

- [ ] Настройки агента меняются в UI и применяются к следующему запуску
- [ ] Бюджет 5 $ в сутки и профиль `light` сохранены и видны в карточке; отрицательный бюджет или несуществующий профиль → отказ с полем и причиной; `concurrency` выше потолка L0 → отказ с названием потолка; сброс → значение по умолчанию; потолок L0 снижен после сохранения → запуски идут в потолок, в карточке это видно ([FR-95](../../architecture/components/platform-module/prd.md) «Недопустимое значение», «Выше потолка платформы», «Потолок снижен после сохранения», «Сброс к умолчаниям»)
- [ ] Runner читает настройки через API модуля, прямой доступ к таблицам закрыт, обновление [ICPlan](../../architecture/components/icplan/README.md) из upstream схему модуля не затрагивает ([FR-96](../../architecture/components/platform-module/prd.md))
- [ ] Смена профиля sandbox во время запуска → активный запуск по прежнему профилю, следующий по новому; бюджет уменьшен ниже потраченного → запуск остановлен с причиной «бюджет» сразу; запуск в `queued` стартует с новыми настройками ([FR-97](../../architecture/components/platform-module/prd.md))
- [ ] История настроек показывает кто, когда, что изменено; откат на версию 3 → новая версия с содержимым версии 3 со следующего запуска; без права `ai_agents` откат → 403 ([FR-98](../../architecture/components/platform-module/prd.md))
- [ ] Импорт YAML из dev создаёт в prod новую версию; ссылка на несуществующий MCP-сервер → отказ с указанием ссылки; в экспорте только ссылки на секреты ([FR-99](../../architecture/components/platform-module/prd.md))
- [ ] Новый тул в списке с подтверждением → следующий вызов ждёт approve; LiteLLM не отвечает при сохранении бюджета → «не применено» и повтор; бюджет в модуле и LiteLLM различается → предупреждение администратору ([FR-100](../../architecture/components/platform-module/prd.md), [FR-108](../../architecture/components/platform-module/prd.md) «LiteLLM admin API недоступен», «OPA не забрал bundle», «Рассинхронизация настроек»)
- [ ] Руководство проекта новым запуском получает слой после системного промпта; длиннее `prompt.guidance_max_chars` → отказ с границей; не задано → слой пропущен ([FR-102](../../architecture/components/platform-module/prd.md))
- [ ] Экспорт → импорт даёт тот же агент
- [ ] Настройки агента — в карточке, проекта — в разделе «ИИ-команда», экземпляра — в God mode; без права `ai_agents` — только чтение, God mode — только владелец экземпляра ([AD-24](../../architecture/decisions/AD-24.yaml))
- [ ] Предложение агента не меняет определение; принято после регрессии и утверждения → новая версия; регрессия хуже → версии нет; откат возвращает предыдущую версию, предложение помечено «откатено»
- [ ] `autonomy_level` R1 → уровень сохранён, со следующего запуска действует политика подтверждений R1 ([FR-95](../../architecture/components/platform-module/prd.md) «Уровень автономии»)
- [ ] Администратор меняет бюджет → изменение сохраняется и попадает в историю ([FR-101](../../architecture/components/platform-module/prd.md) «Есть права»)
- [ ] `prompt.guidance_max_chars` больше 16000 → отказ с названием параметра и границами 0–16000 ([FR-105](../../architecture/components/platform-module/prd.md) «Выше максимума»)
- [ ] Руководство длиннее `prompt.guidance_max_chars` → сохранение отклонено с границей ([FR-102](../../architecture/components/platform-module/prd.md) «Слишком длинное»)
- [ ] Импорт YAML из dev в prod → новая версия агента с тем же содержимым ([FR-99](../../architecture/components/platform-module/prd.md) «Перенос в prod»)
- [ ] Тул добавлен в список с подтверждением → следующий вызов ждёт approve, данные в OPA обновлены ([FR-100](../../architecture/components/platform-module/prd.md) «Новое правило»)
- [ ] [Agent Runner](../../architecture/components/agent-runner/README.md) → API модуля ([I4](../../architecture/components/agent-runner/integrations/I4.yaml)) не ответил за 2 с → вызов прерван, 3 повтора ([FR-107](../../architecture/components/platform-module/prd.md) «Таймаут [I4](../../architecture/components/agent-runner/integrations/I4.yaml)»)
- [ ] Собеседник по [I15](../../architecture/components/platform-module/integrations/I15.yaml) отклонил учётные данные (master key) → вызов не повторяется, событие с причиной ([FR-107](../../architecture/components/platform-module/prd.md) «Аутентификация [I15](../../architecture/components/platform-module/integrations/I15.yaml)»)
- [ ] Импорт с другой схемой → импорт отклоняется с указанием поддерживаемой версии ([FR-56](../../architecture/components/platform-module/prd.md))
- [ ] Импорт с незнакомыми полями → импорт выполняется, незнакомые поля перечислены в предупреждении и не сохраняются ([FR-56](../../architecture/components/platform-module/prd.md))
- [ ] Перенос в prod → в prod создаётся новая версия агента с тем же содержимым ([FR-56](../../architecture/components/platform-module/prd.md))

**Как прокликать:** [ICPlan](../../architecture/components/icplan/README.md): экран настроек агента (бюджет, профиль) → запуск учитывает
