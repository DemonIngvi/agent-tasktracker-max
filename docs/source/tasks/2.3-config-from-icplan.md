## Зачем

Пользователь настраивает агента в UI [ICPlan](../../architecture/components/icplan/README.md); [Harness](../../architecture/components/harness/README.md) должен брать модель, инструкцию и тулы оттуда, а недостающее (лимиты, approve) — из YAML до появления [Platform module](../../architecture/components/platform-module/README.md).

## Что сделать

- Чтение определения агента у [Platform module](../../architecture/components/platform-module/README.md): `GET /platform/runs/:runId/agent` → `{version, definition, settings}` ([I4](../../architecture/components/agent-runner/integrations/I4.yaml), [AD-23](..\design\define-agent-platform\design.md), [R&D](..\..\research\runner-agent-definition.md))
- Минимальный [Platform module](../../architecture/components/platform-module/README.md): этот эндпоинт и сервисный токен Runner; версия запуска — в `agent_run.agent_version` при первом вызове
- Дополнения (лимиты, approve) — настройки [Platform module](../../architecture/components/platform-module/README.md) `agent_settings`, отдельного файла YAML нет; YAML загружается импортом `POST /platform/agents/import` с проверкой ссылок на ресурсы по БД ([AD-26](..\design\define-agent-platform\design.md))
- Версии агента в MVP ([FR-55](../../architecture/components/platform-module/prd.md), решение владельца 2026-10-14): таблица `agent_settings_version`, новая версия по хешу определения при вызове [I4](../../architecture/components/agent-runner/integrations/I4.yaml) ([AD-26](../../architecture/decisions/AD-26.yaml)), поле `Run.settingsVersionId` — запуск на указанной версии, несуществующая — отказ
- Перенос алиаса модели на LiteLLM
- Тулы, навыки, MCP-серверы агента (MCP — `project_resource` и `access_policy`, [AD-23](../../architecture/decisions/AD-23.yaml)) и критерии приёмки задачи (L3) из [ICPlan](../../architecture/components/icplan/README.md) в [`RunBundle`](../../architecture/data/model-RunBundle.yaml)

## Приёмка

- [ ] Изменить `agent.model` или инструкцию агента в [ICPlan](../../architecture/components/icplan/README.md) во время запуска → активный запуск на старой, следующий — на новой ([FR-59](../../architecture/components/platform-module/prd.md) «Изменение настройки»)
- [ ] Сменить модель агента и вернуть прежнюю → новые запуски на новой, затем на прежней; модель, не настроенная в LiteLLM, отклонена ([FR-58](../../architecture/components/platform-module/prd.md) «Замена модели», «Модель без доступа», «Откат модели»)
- [ ] Сохранить агента без `agent.model` → отказ, ошибка называет `agent.model` ([FR-59](../../architecture/components/platform-module/prd.md) «Нет обязательного поля», [FR-54](../../architecture/components/platform-module/prd.md) «Обязательное поле отсутствует»)
- [ ] Выключить агента (`agent.enabled = false`) → в списке «выключен», делегирование отклонено с причиной ([FR-8](../../architecture/components/icplan/prd.md) «Агент выключен», [FR-54](../../architecture/components/platform-module/prd.md) «Выключение агента»)
- [ ] Остановить Runner дольше порога → агенты платформы «не в сети»; запустить → «в сети» ([FR-8](../../architecture/components/icplan/prd.md))
- [ ] БД [ICPlan](../../architecture/components/icplan/README.md) недоступна → определения не читаются, запуски не стартуют ([FR-60](../../architecture/components/platform-module/prd.md) «S1 недоступно», [FR-62](../../architecture/components/platform-module/prd.md) «БД [ICPlan](../../architecture/components/icplan/README.md) недоступна»)
- [ ] Пользователь без права меняет определение → 403, данные не меняются ([FR-61](../../architecture/components/platform-module/prd.md) «Права по [I20](../../architecture/components/icplan/integrations/I20.yaml)»)
- [ ] Импортировать YAML с лимитами → лимиты в `agent_settings`, следующий запуск получает их в `RunBundle.params` ([FR-56](../../architecture/components/platform-module/prd.md), [AD-26](../../architecture/decisions/AD-26.yaml)); импорт со ссылкой на несуществующий навык → отказ с указанием ссылки ([FR-57](../../architecture/components/platform-module/prd.md) «Битая ссылка»)
- [ ] Запуск, ждущий слота, после правки агента стартует с новой версией; повторная выдача запуска получает ту же версию (`agent_run.agent_version`, [AD-23](../../architecture/decisions/AD-23.yaml))
- [ ] Запрос определения по запуску не в `pending` или агента не `external` → 404; версии нет → 409 ([AD-23](../../architecture/decisions/AD-23.yaml))
- [ ] Завершить запуск → рабочая память M0 уничтожена с sandbox, M1–M6 сохранены; инструкция и навыки агента (M5) поданы в [`RunBundle`](../../architecture/data/model-RunBundle.yaml) из [ICPlan](../../architecture/components/icplan/README.md); профиль с несуществующим уровнем памяти не сохраняется, ошибка валидации ([FR-36](../../architecture/components/memory/prd.md) «Завершение запуска», «Неизвестный уровень»)
- [ ] Шлюз недоступен → смена модели не сохраняется, администратор видит причину «проверить модель нельзя»; правка без смены модели сохраняется ([FR-58](../../architecture/components/platform-module/prd.md))
- [ ] Значение по умолчанию → применяется значение по умолчанию: нет ([FR-59](../../architecture/components/platform-module/prd.md))
- [ ] Повтор [I1](../../architecture/components/agent-runner/integrations/I1.yaml) без дублей → дубля нет: аренда: выдаётся одному Runner ([FR-61](../../architecture/components/platform-module/prd.md))
- [ ] Таймаут [I1](../../architecture/components/agent-runner/integrations/I1.yaml) → вызов прерывается; повтор: backoff до 60 с ([FR-61](../../architecture/components/platform-module/prd.md))
- [ ] Импорт с неверной схемой → импорт отклоняется ([FR-62](../../architecture/components/platform-module/prd.md))
- [ ] Удалён ресурс, на который ссылаются → удаление отклоняется ([FR-62](../../architecture/components/platform-module/prd.md))
- [ ] Запуск с `settingsVersionId` = 2 при актуальной версии 3 → Runner получает определение версии 2, `agent_run.agent_version = 2`, повторная выдача — та же ([FR-55](../../architecture/components/platform-module/prd.md) «Запуск на прежней версии»)
- [ ] Изменить инструкцию агента → создаётся версия 4, версии 1–3 читаются ([FR-55](../../architecture/components/platform-module/prd.md) «Новая версия»)
- [ ] Запуск с `settingsVersionId`, которой нет → запуск отклонён с ошибкой версии (409), `agent_run` не получает версию ([FR-55](../../architecture/components/platform-module/prd.md) «Несуществующая версия»)

**Как прокликать:** [ICPlan](../../architecture/components/icplan/README.md): поменять инструкцию агента → делегировать → ответ по новой инструкции
