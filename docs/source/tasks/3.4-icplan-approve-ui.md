## Зачем

Пауза на approve из 1.5 должна управляться из задачи [ICPlan](../../architecture/components/icplan/README.md), иначе опасные действия блокируют работу.

## Что сделать

- Событие «нужен approve» в задаче
- Кнопки одобрить / отклонить: право `work_items.edit` в проекте задачи (роли форка, [AD-26](../../architecture/decisions/AD-26.yaml))
- Передача ответа в Runner → [Harness](../../architecture/components/harness/README.md)
- Вопрос агента (ожидание ответа) и ответ пользователя в задаче

## Приёмка

- [ ] Агент R2 вызвал опасный тул → запуск на паузе, в задаче запрос с кнопками; «одобрить» → действие выполнено, запуск продолжается ([FR-117](../../architecture/components/guardrails/prd.md) «Агент R2», [FR-5](../../architecture/components/icplan/prd.md) «Подтверждение действия»)
- [ ] «Отклонить» → агент получает отказ, продолжает без действия или завершает запуск ([FR-5](../../architecture/components/icplan/prd.md) «Отказ»)
- [ ] Участник без права `work_items.edit` в проекте задачи нажимает «одобрить» → `POST /agent-runs/:runId/decisions` отвечает 403, кнопок у него нет, запрос открыт ([FR-5](../../architecture/components/icplan/prd.md) «Нет прав на подтверждение», [AD-26](../../architecture/decisions/AD-26.yaml))
- [ ] Решение по уже завершённому запуску или повторное решение по тому же `seq` → 409, в ленте одно решение ([FR-5](../../architecture/components/icplan/prd.md); ошибки `POST /agent-runs/:runId/decisions`)
- [ ] Запрос подтверждения → исполнитель получает уведомление со ссылкой и сроком; без исполнителя — участники с правом `work_items.edit` в проекте; до истечения интервала повтора второго уведомления нет ([FR-6](../../architecture/components/icplan/prd.md))
- [ ] Решения нет дольше `guardrails.approval_timeout` → отказ и запись в ленте ([FR-23](../../architecture/components/harness/prd.md) «Истёк таймаут ожидания»)
- [ ] Агент R4 делает опасное обратимое действие → без паузы, запись в аудите; агент R5 на релизе в prod → пауза на подтверждение ([FR-117](../../architecture/components/guardrails/prd.md) «Агент R4», «Релиз в prod»)
- [ ] Агент задал вопрос (`CUSTOM` `question`) → пользователь ответил в задаче → агент продолжил с ответом ([FR-5](../../architecture/components/icplan/prd.md) «запрос… или вопрос», [FR-23](../../architecture/components/harness/prd.md) «пауза на вопрос пользователю»)

**Как прокликать:** Задача с опасным действием: нажать «одобрить» в [ICPlan](../../architecture/components/icplan/README.md)
