## Зачем

Пользователь поправляет агента без перезапуска, администратор проверяет агента в чате до подключения к процессу и временно выключает агента. Основа есть в [ICPlan](../../architecture/components/icplan/README.md): канал чата раннера (`/agent-chats/*`) с возобновлением сессии и ответ heartbeat запуска.

## Что сделать

- [ICPlan](../../architecture/components/icplan/README.md): признак `agent.enabled` — не создавать и не выдавать запуски выключенного агента; выбор судьбы активных
- [ICPlan](../../architecture/components/icplan/README.md): сообщение агенту по задаче при активном запуске прикрепляется к запуску; ответ heartbeat отдаёт сообщения и признак отмены
- Runner: читать сообщения и отмену из heartbeat, передавать в [Harness](../../architecture/components/harness/README.md) ([I7](../../architecture/components/agent-runner/integrations/I7.yaml))
- [Harness](../../architecture/components/harness/README.md): указания пользователя в цикле, «стоп»
- Runner: обслуживать канал чата [ICPlan](../../architecture/components/icplan/README.md) для проверки агента; изменение задач из тестового чата — с подтверждением

## Приёмка

- [ ] Сообщение во время запуска учтено агентом на следующем шаге, в истории «получено агентом»
- [ ] Выключенный агент не получает запусков; после включения очередь разбирается
- [ ] В тестовом чате изменение задачи требует подтверждения
- [ ] Сообщение пришло после завершения запуска → создаётся новый запуск с контекстом чата; сообщение «стоп» → запуск завершается с итогом сделанного ([FR-10](../../architecture/components/icplan/prd.md) «Запуск завершён», «Стоп»; [FR-28](../../architecture/components/harness/prd.md) «Стоп»)
- [ ] Сообщение во время вызова тула → учитывается после завершения тула, в событиях «учтено» ([FR-28](../../architecture/components/harness/prd.md) «Указание», «Во время тула»)
- [ ] Выключить агента с «доделать» → активные завершаются, новые не создаются, у задач причина «агент выключен»; с «отменить» → активные отменены, Runner узнаёт по heartbeat ([FR-11](../../architecture/components/icplan/prd.md) «Выключение», «Отмена активных», «Включение»)
- [ ] Сообщение во время работы → сообщение прикреплено к запуску, Runner получает его со следующим heartbeat, в истории «получено агентом» ([FR-10](../../architecture/components/icplan/prd.md))
- [ ] Mock-модель → ответы по сценарию mock, затрат нет ([FR-12](../../architecture/components/icplan/prd.md))

**Как прокликать:** чат с агентом на mock-LLM → ответ и шаги в чате; задача в работе → написать «используй pytest» → в чате запуска «учтено»
