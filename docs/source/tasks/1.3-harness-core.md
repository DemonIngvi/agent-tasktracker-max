## Зачем

Ядро MVP: агентский цикл, собранный из конфига. Всё остальное (Runner, ICPlan) — обвязка вокруг него.

## Что сделать

- Пакет harness (Python): загрузка YAML, сборка системного промпта и скиллов
- Граф LangGraph `context → llm → tools → context`, LLM-клиент на LiteLLM
- Свой интерфейс harness (вход: определение + задача; выход: события + итог), LangGraph за ним
- CLI: `harness run --agent a.yaml --task "..."`
- Тесты на mock-LLM: текстовый ответ, вызов тула, ошибка модели
- Сборка запроса к модели по слоям и параметрам `model.*`, `drop_params`, учёт размышлений

## Приёмка

- [ ] Агент из YAML отвечает на задачу через mock
- [ ] Цикл с вызовом тула проходит и возвращает итог
- [ ] Ошибка модели → повтор → статус error
- [ ] Агент стартует с определением и задачей → доступны только тулы и скиллы из определения; битое определение → запуск завершён с ошибкой `invalid_definition`; скилл не найден → ошибка с именем скилла (FR-19)
- [ ] Harness вызывает модель по алиасу → запрос уходит в LiteLLM с ключом агента; прямой вызов провайдера из sandbox недоступен; шлюз не отвечает → повтор с задержкой, после лимита ошибок `failed` (FR-21)
- [ ] Агент вызвал тул → событие доступно Observability до завершения запуска; события с задержкой упорядочиваются по `seq`; модель без `reasoning_content` → без `REASONING_*`; Runner не принимает события → Harness буферизует и дошлёт (FR-24)
- [ ] LiteLLM недоступен → повтор с backoff, после `circuit.max_errors` статус `failed` (FR-34)
- [ ] Скилл с инструкциями и тулами подключён → агент получает оба; скилл без тулов → набор тулов не меняется; тул скилла вне allowlist → скилл подключён без него, событие-предупреждение (FR-181)
- [ ] Прототип 1.3.9: AG1–AG5 замерены для LangGraph и OpenAI Agents SDK, статус LangGraph в TECHNOLOGIES обновлён
- [ ] Скилл недоступен → запуск завершается с ошибкой и именем отсутствующего скилла (FR-19)
- [ ] Несколько тулов за шаг → оба проходят G2 по очереди и выполняются, результаты возвращаются в одном следующем шаге; при `false` (по умолчанию) модель запрашивает по одному (FR-20)
- [ ] Ответ без тулов → цикл завершается, итог передаётся дальше (FR-20)
- [ ] Модель без рассуждений → событий `REASONING_*` нет, реплики агента о намерении отдаются (FR-24)
- [ ] Потребитель недоступен → Harness буферизует их и дошлёт, не теряя шагов (FR-24)
- [ ] Состояние цикла → checkpoint уходит в Runner по I12 и пишется в S5; на диске среды его нет (FR-32)
- [ ] Файлы результата → файл пишется в `/workspace` и перечисляется в `RunResult`, публикацию выполняет Runner (FR-32)
- [ ] Аутентификация I8 → вызов не повторяется, событие с причиной (FR-33)
- [ ] Неидемпотентный вызов I9 → автоматического повтора нет, решение принимает вызывающий (FR-33)
- [ ] Таймаут I7 → вызов прерывается; повтор: переподключение с последнего `seq` (FR-33)
- [ ] Checkpointer недоступен → пауза на approve невозможна — опасные действия отклоняются (FR-34)
- [ ] Попытка отменить правила → правила системного промпта платформы действуют, событие «конфликт слоёв» (FR-30)
- [ ] Порядок слоёв → запрос содержит слои по порядку, у каждого в событиях указан источник и версия (FR-30)
- [ ] Скилл с недоступным тулом → скилл подключается без этого тула, событие-предупреждение (FR-181)

**Как прокликать:** CLI-запуск агента на сценарии mock; после 2.6 — из задачи ICPlan
