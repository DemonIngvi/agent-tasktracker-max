# R&D: обоснование решений

← README · architecture.md · design.md (решения AD-1–AD-14)

Исследования, на которых основаны решения. Проводятся по методологии R&D v3.1: цепочка «потребность → ключевые функции → ценность → перенос → встраивание → спор ролей → выбор → последствия», ворота между этапами, первая страница — ответ и микропрезентация на 3 минуты (почему так). Что из исследований меняется в документах — сводка последствий R&D. Колонка «Методология»: **v3.1** — оформлено полностью; **v1 + альтернативы** — нужно перевести на v3.1.
