## Истории

### US-HAR-01 {#us-har-01}

**Как** агент-исполнитель (персона Аг), **я хочу** выполнить задачу по инструкции, используя модель и тулы, **чтобы** дать пользователю результат.

**Точка входа:** задание `RunBundle`

**Участвует в цепочках ICPlan:** US-ICP-01, US-ICP-08, US-ICP-09, US-ICP-19, US-ICP-02, US-ICP-16, US-ICP-24

**Критерии приёмки:**

- [ ] Цикл модель → тулы → итог
- [ ] Тул вернул ошибку → агент учитывает и продолжает
- [ ] Модель недоступна → fallback или завершение `error` с причиной

**Требования:** Агентский цикл · Инициализация из определения агента · MCP-сервер ICPlan

### US-HAR-02 {#us-har-02}

**Как** пользователь icplan (персона П), **я хочу** подтвердить опасное действие агента, **чтобы** агент не сделал необратимого без меня.

**Точка входа:** карточка задачи, уведомление

**Участвует в цепочках ICPlan:** US-ICP-03

**Критерии приёмки:**

- [ ] Опасное действие → пауза, запрос в задаче
- [ ] Одобрено → выполняется
- [ ] Отклонено или таймаут → не выполняется, агент продолжает без него

**Требования:** Пауза и возобновление · G2 Action

### US-HAR-03 {#us-har-03}

**Как** пользователь icplan (персона П), **я хочу** получить проверенный результат, **чтобы** не проверять очевидное вручную.

**Точка входа:** итог запуска

**Критерии приёмки:**

- [ ] Итог проверяется по критериям приёмки задачи
- [ ] Не прошёл → агент дорабатывает в пределах лимита
- [ ] Лимит исчерпан → `failed` с отчётом проверки

**Требования:** Quality gate результата

### US-HAR-04 {#us-har-04}

**Как** эксплуатация (devops) (персона Э), **я хочу** чтобы агент не зацикливался и не тратил лишнее, **чтобы** контролировать затраты.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Повтор одинакового вызова N раз → стоп с причиной
- [ ] Лимит шагов или времени → `limit`
- [ ] Резкий рост расхода → стоп и уведомление

**Требования:** Защита от зацикливания · Лимит шагов и времени · Аномальный расход

### US-HAR-05 {#us-har-05}

**Как** эксплуатация (devops) (персона Э), **я хочу** чтобы падение процесса не теряло работу, **чтобы** не перезапускать с нуля.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Checkpoint после каждого шага
- [ ] Перезапуск → продолжение с последнего checkpoint
- [ ] Checkpoint недоступен → опасные действия отклоняются, событие

**Требования:** Пауза и возобновление · Поведение при отказах зависимостей

### US-HAR-06 {#us-har-06}

**Как** агент-исполнитель (персона Аг), **я хочу** получить указание пользователя во время работы и учесть его, **чтобы** не уйти в неверную сторону до конца запуска.

**Точка входа:** чат задачи (US-ICP-10)

**Участвует в цепочках ICPlan:** US-ICP-10

**Критерии приёмки:**

- [ ] Сообщение пользователя → включается в контекст на следующем шаге
- [ ] Сообщение «стоп» → завершение с итогом сделанного
- [ ] Сообщение во время вызова тула → после его завершения

**Требования:** Указания пользователя в цикле · Указания пользователя во время запуска

### US-HAR-07 {#us-har-07}

**Как** агент-исполнитель (персона Аг), **я хочу** задать пользователю вопрос и подождать ответа, **чтобы** не гадать при неясном задании.

**Точка входа:** —

**Участвует в цепочках ICPlan:** US-ICP-11, US-ICP-03

**Критерии приёмки:**

- [ ] Вопрос → пауза `waiting`, слот модели свободен
- [ ] Ответ → продолжение с ответом в контексте
- [ ] Таймаут → завершение с причиной «нет ответа»

**Требования:** Пауза и возобновление · Подтверждения и ответы
