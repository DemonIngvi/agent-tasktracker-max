## Истории

### US-RUN-01 {#us-run-01}

**Как** агент-исполнитель (персона Аг), **я хочу** забрать запуск из очереди и исполнить его в изолированной среде, **чтобы** задача ICPlan выполнялась агентом платформы.

**Точка входа:** очередь ICPlan

**Участвует в цепочках ICPlan:** US-ICP-01, US-ICP-08, US-ICP-09, US-ICP-19, US-ICP-04, US-ICP-16, US-ICP-17, US-ICP-22, US-ICP-27, US-ICP-07

**Критерии приёмки:**

- [ ] Запуск взят → создан sandbox, Harness получил задание
- [ ] Агент выключен или нет настроек → `agent_unavailable`, sandbox не создаётся
- [ ] Нет свободного слота → запуск ждёт в `queued`

**Требования:** Запуск из очереди ICPlan · Статусы запуска · Возврат результата

### US-RUN-02 {#us-run-02}

**Как** эксплуатация (devops) (персона Э), **я хочу** переключить платформу в последовательный режим, **чтобы** разбирать проблемы по одному запуску.

**Точка входа:** конфиг деплоя

**Критерии приёмки:**

- [ ] `sequential` → одновременно один запуск
- [ ] Обратно `parallel` → параллельно по слотам
- [ ] Переключение при активных запусках → они доделываются, новые по новому режиму

**Требования:** Режим последовательно или параллельно

### US-RUN-03 {#us-run-03}

**Как** эксплуатация (devops) (персона Э), **я хочу** чтобы агенты не перегружали общую модель, **чтобы** не упираться в лимиты провайдера.

**Точка входа:** конфиг деплоя

**Участвует в цепочках ICPlan:** US-ICP-18, US-ICP-07

**Критерии приёмки:**

- [ ] Слоты модели заняты → запуск ждёт
- [ ] Освободился слот → следующий по порядку стартует
- [ ] Лимит модели изменён → действует для новых стартов

**Требования:** Планирование по слотам

### US-RUN-04 {#us-run-04}

**Как** эксплуатация (devops) (персона Э), **я хочу** чтобы ожидание подтверждения не блокировало платформу, **чтобы** одна ждущая задача не держала всех.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Запуск ждёт approve → глобальный и модельный слоты освобождены
- [ ] Слот задачи держится — второго запуска по задаче нет
- [ ] Подтверждение пришло → запуск занимает слот заново

**Требования:** Слоты при ожидании подтверждения

### US-RUN-05 {#us-run-05}

**Как** эксплуатация (devops) (персона Э), **я хочу** чтобы падение Runner не теряло работу, **чтобы** не перезапускать задачи вручную.

**Точка входа:** —

**Участвует в цепочках ICPlan:** US-ICP-06

**Критерии приёмки:**

- [ ] Runner упал → аренда истекает, запуск снова в очереди
- [ ] Второй Runner → слоты общие, лимиты не превышаются
- [ ] Досылка событий после восстановления без дублей

**Требования:** Общие слоты для нескольких Runner · Поведение при отказах зависимостей

### US-RUN-06 {#us-run-06}

**Как** эксплуатация (devops) (персона Э), **я хочу** вывести Runner из работы для обновления, **чтобы** обновлять без потери запусков.

**Точка входа:** команда эксплуатации / rolling update

**Критерии приёмки:**

- [ ] Режим «не брать новые» → активные доделываются, новые не берутся
- [ ] Все активные завершены → Runner можно остановить
- [ ] Таймаут вывода → оставшиеся запуски возвращаются в очередь

**Требования:** Развёртывание
