## Истории

### US-GRD-01 {#us-grd-01}

**Как** администратор платформы (персона А), **я хочу** включать и выключать проверки по точкам, **чтобы** подстраивать строгость под среду.

**Точка входа:** конфиг деплоя

**Критерии приёмки:**

- [ ] G1–G4 включаются отдельно
- [ ] Выключение G2 в prod → предупреждение
- [ ] Изменение → после перезапуска модуля

**Требования:** Включение и выключение точек

### US-GRD-02 {#us-grd-02}

**Как** пользователь icplan (персона П), **я хочу** понимать, почему агенту отказали, **чтобы** исправить задачу или попросить доступ.

**Точка входа:** чат запуска в задаче

**Критерии приёмки:**

- [ ] Отказ → причина и правило в чате запуска в задаче
- [ ] Отказ по бюджету → «бюджет исчерпан»
- [ ] Отказ OPA недоступен → «проверка недоступна, действие запрещено»

**Требования:** Аудит срабатываний · Движок решений для G1 и G2

### US-GRD-03 {#us-grd-03}

**Как** владелец продукта (персона ВП), **я хочу** чтобы траты не выходили за бюджет, **чтобы** контролировать расходы.

**Точка входа:** —

**Участвует в цепочках ICPlan:** US-ICP-01, US-ICP-18

**Критерии приёмки:**

- [ ] Бюджет агента исчерпан → запуски отклоняются
- [ ] Бюджет проекта ограничивает агентов
- [ ] Аномальный расход → стоп и уведомление

**Требования:** Иерархия бюджетов токенов и денег · Аномальный расход

### US-GRD-04 {#us-grd-04}

**Как** эксплуатация (devops) (персона Э), **я хочу** мгновенно остановить агента или всю платформу, **чтобы** остановить инцидент.

**Точка входа:** команда эксплуатации (API kill switch) / карточка агента или God mode → «Платформа»

**Критерии приёмки:**

- [ ] Стоп агента → его запуски отменены, новые отклоняются
- [ ] Стоп всех → все запуски отменены
- [ ] Снятие стопа → работа возобновляется

**Требования:** Аварийная остановка

### US-GRD-05 {#us-grd-05}

**Как** безопасность (персона Б), **я хочу** просматривать журнал срабатываний guardrails, **чтобы** находить опасные попытки агентов.

**Точка входа:** Настройки → журнал guardrails

**Критерии приёмки:**

- [ ] Журнал: агент, задача, точка, правило, решение
- [ ] Фильтр по агенту, точке, периоду
- [ ] Записи хранятся по политике хранения

**Требования:** Аудит срабатываний

### US-GRD-06 {#us-grd-06}

**Как** администратор платформы (персона А), **я хочу** задать правила: какие тулы требуют подтверждения, **чтобы** агент спрашивал там, где риск.

**Точка входа:** агент → правила

**Критерии приёмки:**

- [ ] Тул в списке approval → пауза на подтверждение
- [ ] Тул вне allowlist → отказ
- [ ] Правило с ошибкой → не применяется, прежнее действует

**Требования:** G2 Action · Единый источник правил
