## Истории

### US-LLM-01 {#us-llm-01}

**Как** администратор платформы (персона А), **я хочу** сменить модель агента без изменения агента, **чтобы** переходить на лучшие или дешёвые модели.

**Точка входа:** LiteLLM UI / Платформа

**Критерии приёмки:**

- [ ] Смена алиаса → все агенты алиаса на новой модели
- [ ] Новая модель недоступна → fallback
- [ ] Откат алиаса → со следующего вызова

**Требования:** Алиасы моделей · Смена модели агента

### US-LLM-02 {#us-llm-02}

**Как** тестировщик / qa (персона QA), **я хочу** разрабатывать и тестировать без ключей провайдера, **чтобы** не тратить деньги на отладку.

**Точка входа:** алиас модели

**Участвует в цепочках ICPlan:** US-ICP-24

**Критерии приёмки:**

- [ ] Алиас mock → скриптовые ответы и вызовы тулов
- [ ] Сценарий закончился → ответ по умолчанию
- [ ] Тот же агент на реальной модели — сменой алиаса

**Требования:** Mock-модель для разработки

### US-LLM-03 {#us-llm-03}

**Как** пользователь icplan (персона П), **я хочу** видеть стоимость работы агента по задаче, **чтобы** понимать цену результата.

**Точка входа:** карточка задачи

**Участвует в цепочках ICPlan:** US-ICP-01, US-ICP-12

**Критерии приёмки:**

- [ ] Токены и $ по задаче
- [ ] По запускам задачи
- [ ] Затраты недоступны → пометка, без ошибки

**Требования:** Атрибуция затрат · Затраты

### US-LLM-04 {#us-llm-04}

**Как** эксплуатация (devops) (персона Э), **я хочу** чтобы сбой провайдера не останавливал работу, **чтобы** не терять задачи.

**Точка входа:** —

**Критерии приёмки:**

- [ ] Провайдер недоступен → fallback-модель
- [ ] Fallback тоже недоступен → `failed` с причиной
- [ ] Rate limit → повтор с задержкой

**Требования:** Fallback · Несколько провайдеров

### US-LLM-05 {#us-llm-05}

**Как** владелец продукта (персона ВП), **я хочу** получать отчёт о затратах по агентам, проектам и моделям за период, **чтобы** планировать бюджет.

**Точка входа:** дашборд затрат

**Участвует в цепочках ICPlan:** US-ICP-28

**Критерии приёмки:**

- [ ] Отчёт за период с разбивкой
- [ ] Экспорт в CSV
- [ ] Нет данных за период → пустой отчёт

**Требования:** Атрибуция затрат · Учёт токенов
