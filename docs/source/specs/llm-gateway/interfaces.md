## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

Значения и границы пересматриваются по статистике запусков (3.9) и нагрузочному тесту (4.8); правило — виды спек, таблица параметров.

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию | Почему так по умолчанию | Мин | Макс | Тип | На что опираться при выборе |
|---|---|---|---|---|---|---|---|---|---|
| `drop_params` | Отбрасывать параметры, которые модель не поддерживает | L0 | S9 (`litellm config.yaml`) | true | одно определение агента работает на разных моделях | false | true |  | false — для отладки несовместимости |
| `model_list` | Алиасы → модели | L0 | S9 (`litellm config.yaml`) | team-default → mock | разработка без ключей провайдера (mock-LLM) | 1 алиас | — | список алиасов LiteLLM | prod: реальные модели под задачи агентов |
| `fallbacks` | Резервные модели | L0 | S9 (`litellm config.yaml`) | нет | резервная модель может быть дороже или хуже — включать осознанно | нет | список алиасов | список алиасов LiteLLM | доступность провайдера и сопоставимое качество |
| `key.max_budget` | Бюджет virtual key | L1 | S6 | из Platform module | единый источник — `budget.daily_usd` | 0 $ | `budget.daily_usd` | число $ | см. control-plane |
| `key.rpm / tpm` | Запросы и токены в минуту | L1 | S6 | 60 / не ограничено | rpm = `rate_limit` агента; токены ограничивает бюджет | 10 / 10 000 | лимиты аккаунта провайдера | число / число | лимиты провайдера / число агентов |
| `guardrails` | G4: PII, injection, модерация (ключ `guardrails` в `config.yaml` LiteLLM) | L0 | S9 (`litellm config.yaml`) | выкл | см. `g4.enabled` (guardrails) | выкл | вкл |  | см. guardrails |

## Нагрузка и развёртывание

| | |
|---|---|
| **Нагрузка** (гипотеза, R&D) | 0.4–1 RPS, ~55 тыс. токенов/мин в пике; ответ модели 5–20 с, стрим |
| **Развёртывание** (R&D) | LiteLLM — Deployment `litellm` в `itsaplan-agents`, 2 реплики за Service ClusterIP; БД `litellm` через PgBouncer; админка без ingress |

Детали форматов — потоки.

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| Провайдер недоступен | ошибки I13 | fallback-модель; если нет — ошибка вызова | переключение алиаса |
| БД `litellm` недоступна | ошибки I14 | проверка бюджетов невозможна — вызовы отклоняются | восстановление БД |
| Нет ключа провайдера | ошибка авторизации провайдера | алиас недоступен | добавление ключа в Secret |
| LiteLLM упал | health-check | вызовы Harness получают ошибку, circuit breaker | реплики, перезапуск |
