## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | Platform module | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача ICPlan / `Run` | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Параметры модуля

Значения и границы пересматриваются по статистике запусков (3.9) и нагрузочному тесту (4.8); правило — виды спек, таблица параметров.

| Параметр | Что задаёт | Уровень | Хранилище | По умолчанию | Почему так по умолчанию | Мин | Макс | Тип | На что опираться при выборе |
|---|---|---|---|---|---|---|---|---|---|
| `process.issue_type` | Тип задачи, которому принадлежит процесс | L2 | S1 | — (обязательный) | процесс задаётся для типа | тип проекта | тип проекта | ссылка тип проекта | у типа не более одного процесса |
| `step.column` | Колонка шага процесса | L2 | S1 | — (обязательный) | шаг = колонка | колонка проекта | колонка проекта | ссылка колонка проекта | колонка не повторяется в процессе |
| `step.agent` | Агент шага (пусто — ручной шаг) | L2 | S1 | нет | шаг ручной, пока агента не назначили | нет | агент — участник проекта | ссылка агент | агент, проверенный на тестовой задаче (US-ICP-24) |
| `step.on_success / on_failure` | Переходы шага по итогу запуска | L2 | S1 | следующий шаг / остаться | линейный процесс, ошибка не двигает задачу | шаг процесса | шаг, другой процесс, «завершить» | ссылка шаг / ссылка шаг | куда должна уйти задача по итогу |
| `step.transitions` | Переходы шага по причинам `[{reason, to}]` (FR-205) | L2 | S1 | пусто: только `on_success / on_failure` | совместимость с линейным процессом | справочник причин (`done`, `defect`, `spec_question`, `blocked`) | шаг, человек, «завершить» | список | `spec_question` — к владельцу знания или человеку |
| `step.max_runs` | Лимит запусков на шаге | L2 | S1 | 3 | как `AGENT_RUN_MAX_ATTEMPTS` ICPlan: запуск + 2 доработки | 1 | 10 |  | больше 10 — проблема постановки, нужен человек |
| `process.max_total_runs` | Лимит запусков по задаче (вся цепочка) | L2 | S1 | 8 | принято владельцем 2026-10-14 как значение по умолчанию, пересмотр по замеру (agent-chain.md, ворота G9): цепочка из 3 шагов + 2 круга возврата | 1 | 30 |  | рост — только если замер покажет, что лимит режет полезные цепочки |
| `process.no_progress_rounds` | Число кругов без нового результата до остановки | L2 | S1 | 2 | принято владельцем 2026-10-14 как значение по умолчанию, пересмотр по замеру (agent-chain.md, ворота G9) | 1 | 5 |  | круг = возврат на уже пройденный шаг |
| `process.verify_default` | Шаг-проверка другим агентом перед завершением | L2 | S1 | вкл | независимая проверка по умолчанию (AD-27); выкл — базовая линия «один агент» | выкл | вкл |  | выкл — только для замера и однозначно простых процессов |
| `step.require_review` | Проверка пользователем после шага | L2 | S1 | выкл | процесс автоматический по умолчанию | выкл | вкл |  | вкл — для необратимых и внешних шагов (релиз, отправка клиенту) |
| `issue.review_with_me` | Проверять со мной все шаги задачи | L3 | S1 | выкл | решает пользователь для важной задачи | выкл | вкл |  | важность задачи |
| `issue.process_paused` | Процесс по задаче остановлен | L3 | S1 | нет | процесс идёт | нет | да |  | да — пока пользователь разбирается |
| `review_reminder_hours` | Напоминание о непроверенном результате | L0 | S9 | 24 | рабочий день | 1 | 168 |  | ритм работы команды |
| `project.actions` | Действия проекта (`project_action`): условие → эффект «делегировать агенту» | L2 | S1 | нет | автоматизация — по выбору администратора | нет | Действия проекта | список actions | признаки, которых нет в процессе (метка, поле) |

## Отказы (FMEA)

| Отказ | Обнаружение | Поведение | Восстановление |
|---|---|---|---|
| Агент правила не участник проекта | проверка при срабатывании | запуск не создаётся, предупреждение в истории | администратор правит правило |
| Очередь недоступна | ошибка постановки | делегат установлен, worker повторяет постановку с backoff до 60 с, не более 5 попыток; не удалось — запись «запуск не поставлен» в истории задачи и уведомление владельцу процесса | «повторить шаг» владельцем процесса или исполнителем (FR-202) |
| Цикл переходов (задача возвращается на шаг) | вход в шаг в (`step.max_runs` + 1)-й раз | запуск не создаётся, переход при ошибке с причиной «лимит шага», уведомление владельцу процесса | правка процесса; повтор сверх лимита — владелец процесса (FR-202) |
| БД ICPlan (S1) недоступна | ошибки 5xx API ICPlan при приёме итога | итог не принимается и остаётся у Runner, Runner повторяет отправку с backoff (FR-17); переход по итогу не выполняется | итог принят после восстановления → переход по итогу, идемпотентно по `run_id` |
