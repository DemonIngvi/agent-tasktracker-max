## Уровни конфигурации

| Уровень | Что | Где хранится | Область |
|---|---|---|---|
| L0 | Конфиг деплоя | S9 | платформа целиком: адреса, переключатели G1–G4, режим планирования, потолки лимитов |
| L1 | [Platform module](../../platform-module/README.md) | S2 | агент: бюджеты, профили, данные guardrails, флаги планирования |
| L2 | Определение агента | S1 (+ YAML импорт) | агент: модель, инструкция, тулы, навыки, MCP, лимиты запуска |
| L3 | Запуск | задача [ICPlan](../../icplan/README.md) / [`Run`](../../../data/model-Run.yaml) | версия агента, критерии приёмки, задание |

Правило: значение берётся с самого конкретного уровня (L3 → L0), но не выше потолка L0.

## Правила записи по уровням {#write-rules}

Что, когда и кем пишется в каждый уровень и какие проверки проходят **до** записи. Запись, не прошедшая проверку, не выполняется; причина — в событиях запуска.

| Уровень | Когда пишется | Что пишется | Кто запускает | Проверки до записи | При отказе проверки |
|---|---|---|---|---|---|
| M0 | на каждом шаге цикла | сообщения модели, вывод тулов (обрезанный до `max_result_kb`) | [Harness](../../harness/README.md) | размер окна (сжатие при 80%) | сжатие истории, итог сжатия в M0 |
| M1 | на каждое сообщение в треде, чате, комментарии | текст сообщения, автор, время | [ICPlan](../../icplan/README.md) автоматически | маскирование секретов; уровень M1 разрешён профилем чтения следующих запусков | сообщение пишется с маской; без M1 в профиле — не читается агентом |
| M2 | в конце запуска; при вердикте пользователя | статус, итог (до 2 тыс. символов), затраты, вердикт и заметка | Runner; [ICPlan](../../icplan/README.md) (вердикт) | идемпотентность по `run_id`; маскирование; вердикт — один на запуск | повтор — без дубля; второй вердикт заменяет первый с записью в истории |
| M3 | когда агент продвинулся: шаг сделан, найдена блокировка, перед завершением | [`M3Record`](../../../data/model-M3Record.yaml): сделано, дальше, блокировки | агент тулом памяти | M3 в профиле записи; область видимости (задача агента); схема [`M3Record`](../../../data/model-M3Record.yaml); размер ≤ `m3_max_kb`; нет секретов; версия не старше текущей | отказ тулу с причиной; агент исправляет или продолжает без записи |
| M4 | после MVP | факты с источником | агент тулом / администратор импортом | после MVP: дедупликация, источник обязателен, область видимости | — |
| M5 | при изменении агента | инструкция, навыки | администратор (Registry) | валидация определения агента | версия не сохраняется |
| M6 | при изменении документа проекта | документы проекта | пользователи [ICPlan](../../icplan/README.md) | права [ICPlan](../../icplan/README.md); агенту запись запрещена | агенту — отказ тула |

## Адаптеры обучения {#adapters}

Внутренние контракты ядра ([AD-28](..\..\..\..\source\design\define-agent-platform\design.md), [R&D](..\..\..\..\research\agent-chain.md)): движок каждого вида заменяется без правок ядра (сценарий С4); плагины не импортируют внутренности ядра. Реализация по умолчанию — за каждым адаптером; все адаптеры проверяет контрактный тест (fitness F4: две реализации, 100%).

| Адаптер | Вид | Операции | Реализация по умолчанию | Не берём |
|---|---|---|---|---|
| `MemoryStore` | факты | `write` (с источником, исходом, TTL), `search`, `delete`, `ttl` | Mem0 (Apache-2.0) на pgvector (HNSW); Graphiti — только если понадобятся временные факты | LangMem (завязан на LangGraph) |
| `PlaybookStore` | плейбук | приращения helpful/harmful, детерминированный merge, чтение, удаление | паттерн ACE: код свой по схеме | перезапись плейбука LLM |
| `SkillRegistry` | навыки | регистрация с верификатором (О5), версии, чтение | формат Agent Skills (name, description, тело до 5000 токенов), версии в git | самогенерируемые навыки без верификатора |
| `PromptOptimizer` | оптимизация промптов | пакетный запуск на отложенном наборе, результат — предложение | DSPy + GEPA (MIT), пакетно | непрерывная оптимизация |
| `SnapshotStore` | снимки | создать, список, восстановить (перенос указателя), удалить по сроку | неизменяемые версии + указатель; формат по образцу Letta Agent File | — |

Снимки и указатель описывает agent-registry [FR-64](../../platform-module/prd.md), [FR-65](../../platform-module/prd.md).
