### Порядок работы и сценарии

#### Порядок работы


Каждый уровень памяти **кто-то пишет** и **кто-то читает**. Агент сам пишет только M3 (и M4 после MVP); остальные уровни заполняют [ICPlan](../../icplan/README.md), Runner, [Harness](../../harness/README.md) и люди. Проверки до записи — [правила записи по уровням](agent-memory-interfaces.md).

**Передача между шагами ([AD-20](../../../decisions/AD-20.yaml)).** M3 шага — его передача следующему: `artifacts` (ссылки, а не содержимое), `questions`, `criteriaNext` (предложенные критерии; попадают в чек-лист задачи с пометкой автора и подтверждаются по `criteria_approval` шага). Следующему шагу **не** передаются рабочий контекст M0, промпты и вывод тулов — они остаются в событиях запуска.
