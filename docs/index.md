# Как читать проект

Agent TaskTracker Max: агентная платформа, которая выполняет задачи трекера ICPlan. Проект перенесён из `agent-architecture` в новую структуру документации и правится здесь.

| Что | Где |
| --- | --- |
| Требования | PRD |
| Решения | Architecture Spine, источник `docs/architecture/decisions` |
| Устройство системы | `docs/architecture` |
| Истории | Эпики |
| Качество | `_quality/check-report.yaml` |
| Что требует разбора | Отчёт о переносе |
| Исследования, задачи, техспеки, API | `docs/source`, разделы R&D, Компоненты и Планы |
